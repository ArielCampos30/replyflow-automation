# ReplyFlow Automation

Proyecto demostrativo de portfolio orientado a automatización de atención comercial, mensajería omnicanal simulada, handoff humano y procesamiento de eventos.

## Objetivo

Mostrar una solución distinta a un CRM tradicional: una central de atención tipo inbox con conversaciones, automatizaciones visuales, reglas por palabras clave, simulación de webhooks, contactos y analítica operativa.

## Funcionalidades incluidas

- bandeja omnicanal simulada;
- conversaciones estilo inbox/chat;
- canales demo: WhatsApp, Instagram y Web Chat;
- lectura y respuesta manual;
- respuestas rápidas;
- asignación de responsable;
- estados de conversación;
- prioridad;
- etiquetas;
- automatización activable por conversación;
- handoff a atención humana;
- historial operativo por contacto;
- Automation Studio con flujos visuales trigger → condición → acción;
- respuestas automáticas por palabras clave;
- acciones adicionales: etiquetar o derivar;
- creación y pausa de flujos;
- probador de automatizaciones;
- Webhook Lab con payload JSON y pipeline de procesamiento;
- registro técnico de eventos;
- simulación de webhooks;
- directorio de contactos;
- exportación CSV de datos ficticios;
- analítica de canales, estados e intervenciones;
- persistencia local con `localStorage`;
- diseño responsive para escritorio, tablet y celular;
- datos 100% ficticios.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- localStorage

## Importante

Este proyecto es una demo de portfolio. No está conectado a cuentas reales ni a la API oficial de WhatsApp, Instagram u otros servicios de mensajería. Los webhooks, canales, contactos, métricas y eventos son simulados para demostrar interfaz, lógica de automatización y arquitectura de flujo sin presentar integraciones inexistentes.

## Aplicación en proyectos reales

La misma estructura podría evolucionar hacia una implementación real incorporando, según el alcance del cliente:

- backend con Node.js/Express;
- base de datos PostgreSQL;
- autenticación y roles;
- webhooks reales;
- API oficial del proveedor de mensajería;
- colas de procesamiento;
- auditoría e historial persistente.
