# ReplyFlow Automation

Proyecto demostrativo de portfolio orientado a automatización de atención comercial, gestión de conversaciones y captura de leads.

## Objetivo

Mostrar una interfaz funcional de atención multicanal simulada, con bandeja de conversaciones, reglas automáticas, derivación a atención humana, contactos y métricas.

## Bloque 1

Incluye:

- bandeja de conversaciones;
- canales simulados: WhatsApp demo, Instagram y Web;
- lectura y respuesta manual;
- respuestas automáticas por palabras clave;
- activación y pausa de reglas;
- simulador de nuevas consultas;
- derivación a atención humana;
- base de contactos capturados;
- dashboard de métricas;
- persistencia local con `localStorage`;
- diseño responsive para escritorio, tablet y celular;
- datos 100% ficticios.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- localStorage

## Importante

Este proyecto es una demo de portfolio. No está conectado a cuentas reales ni a la API oficial de WhatsApp, Instagram u otros servicios de mensajería.

## Próximos pasos posibles

- API REST con Node.js/Express;
- persistencia PostgreSQL;
- webhooks de demostración;
- autenticación y roles;
- integración oficial de mensajería en un proyecto real, únicamente con credenciales y cuentas autorizadas del cliente.
